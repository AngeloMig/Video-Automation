## Run and verify

```bash
cp .env.example .env.local   # if it doesn't exist
pnpm install
pnpm db:local                # terminal 1: real Postgres, applies migrations
pnpm test                    # terminal 2: stop any worker first, or it steals test jobs
pnpm test:e2e
pnpm typecheck && pnpm lint && pnpm build
```

Use `pnpm dev:all` to run the app. Set `.env.local` keys and restart to enable providers.

**Linux sandbox note:** `pnpm test:e2e` makes its speech fixture with macOS `say`, so it fails on
Linux until that fixture changes. The macOS voice provider also isn't selected there.

**Real services used:** Postgres, Remotion, FFmpeg, Kokoro, macOS `say`, Wikipedia.

**Voices:** Kokoro (`kokoro-js`, Apache-2.0) is the default with no keys. It runs on the worker's CPU
and downloads a 92 MB model once. It has no word timings, so captions are estimated. `kokoro-js`'s
`stream()` never finished in testing, so the adapter calls `generate()` per chunk. macOS `say` now
needs `TTS_PROVIDER=macos-say`, because Apple's license limits it to non-commercial use.

**Never run for real (adapter written, tested only against `tests/fixtures/fake-providers.ts` or not
at all):**

- OpenAI chat, transcription, speech. Stand-in tested. Default models and per-token cost estimates
  in `src/services/openai.ts` come from memory, so check them against current docs and prices.
- Pexels and the YouTube Data API. Stand-in tested. Pexels has paused new API keys (its API page,
  November 2026), so an existing key is needed to use it.
- Pixabay's default footage route has run against the real API. Its search cache is per process, and
  its terms require 24-hour caching. Search is film only (`video_type=film`).
- Footage relevance: `keywordsFromText` guesses poorly (a honey script got a cartoon germ and a
  galaxy), so scripts should use `Line of narration. [search words]`. Results are ranked by matching
  tags, but nothing checks that a clip fits its scene or is bright enough to read (one clip was
  mostly black), so a person has to review the footage.

**Script format:** `Maya: Line. [search words | 18% | small label]`. Two or more names make a
podcast with a separate voice per host. Stats work in every template. Parsing is in
`parseScriptScenes`.

**Formats:** Podcast (`style.podcast`, waveform from loudness measured in `edit.assemble`, so no
browser audio fetch or CORS is involved) and Split Runner (`src/remotion/RunnerGame.tsx`, drawn from
code). Never put real Subway Surfers, MrBeast or other third-party footage in these. Podcast and
Runner fonts come from `@remotion/google-fonts` on first use, so those renders need internet.
Render speed: about 4 seconds per second of video on this Mac, after moving Pixabay to 1080p.
- ElevenLabs. Only the alignment parser is unit tested. No request has been sent, even to a stand-in.
- Supabase Auth and S3/R2. Not tested at all. S3 browser upload also needs bucket CORS.

The first job for whoever gets keys is to run one real video through each provider.

## Product rules (from the user's brief)

- No fake buttons, simulated jobs or invented metrics. Show unsupported metrics as unavailable, and
  use `null`, never 0, for anything unmeasured.
- A missing API key shows a setup state. Mock data only in a labeled design preview.
- Never download or reuse third-party YouTube footage. YouTube is metadata discovery only.
- Require a rights confirmation on uploaded source footage.
- Call it an "estimated content opportunity score". Never claim to predict virality.
- Never report a video as published until the provider confirms it.
- New projects default to approval required. Autonomous publishing is an explicit opt-in.
- Don't overwrite a project's creative settings from AI recommendations without permission.

## Architecture

| Area | Decision | Where |
| --- | --- | --- |
| Web | Next.js 16 App Router. Mutations are server actions over a shared domain layer | `src/app`, `src/server/actions.ts`, `src/server/domain.ts` |
| Worker | Separate process, scaled independently | `src/worker` |
| Database | Postgres via `DATABASE_URL`: Supabase in production, `embedded-postgres` locally | `src/db`, `supabase/migrations` |
| Schema | Drizzle generates `0000_*`. RLS is hand-written in `1000_*`. `db/local-shim.sql` fakes Supabase's auth schema locally only | |
| Tenant isolation | `withUser` sets `role authenticated` and JWT claims in a transaction, so real RLS applies | `src/db/client.ts` |
| Auth | Supabase in production; dev-only local sign-in that refuses to run in production | `src/lib/auth.ts` |
| Jobs | `production_jobs` is the queue: `FOR UPDATE SKIP LOCKED`, leases, fencing, backoff | `src/jobs/queue.ts`, `src/worker/runner.ts` |
| Pipelines | One handler per job kind. Each enqueues the next with an idempotency key | `src/pipelines` |
| Timeline | `TimelineSpec` (zod) is the only description of a video | `src/timeline/spec.ts` |
| Rendering | `src/remotion/Timeline.tsx` draws the spec in both the Player and the render | `src/render/render.ts` |
| Providers | Adapters behind `src/services/types.ts`, selected in `registry.ts`. Base URLs overridable | `src/services` |

**Job chains**

- Faceless, AI: `faceless.research` → `faceless.script` → `faceless.voice` → `faceless.visuals` → `edit.assemble` → `render.video` → `qa.check` → video is `pending_approval`.
- Faceless, own script: starts at `faceless.voice`.
- Clipper: `clip.transcribe` → `clip.detect` → candidates. Each candidate gets `render.video` when the person asks.
- Scene regeneration passes `render: false`, so the new timeline waits for review.

### Rules that are easy to break

- **Worker queries use the RLS-bypassing owner connection, so every one must filter by
  `workspaceId`.** `tests/queue.test.ts` proves a timeline can't render another workspace's asset.
- **A new table needs policies in a new hand-written migration.** Add it to `tests/rls.test.ts` too.
- **Anything visual goes in `src/remotion/Timeline.tsx` with inline styles and no `@/` imports.**
  The worker bundles that folder with webpack, separately from Next.
- **Editor changes go through pure functions in `src/timeline/edit.ts`,** which keeps undo working
  and keeps them unit tested.
- **Job handlers must be safe to re-run.** A crashed job is reclaimed and runs again from the start.
- **Request-side `social_accounts` selects must name columns.** Token columns are revoked.
- **Client forms use `onFormSubmit` from `kit.tsx`, not `<form action>`.** React resets uncontrolled
  inputs after an action, which wiped people's scripts on a failed submit.
- **URL IDs go through `isUuid` first.** Otherwise a malformed ID becomes a 500.

## Known gaps in Phase 1

Stated plainly so no one assumes these exist:

- **Clipper:** no speaker segmentation or topic detection (`transcripts.topics` stays empty). Crop
  position is manual, with no face tracking (brief puts advanced reframing in Phase 3). Audio over
  25 MB after compression, roughly 100 minutes, fails with a clear message and isn't chunked.
- **Faceless:** "supported" means a stored Wikipedia source was cited for a claim. The citation is
  checked to exist, but the model's reading of the source isn't independently verified. Web research
  beyond Wikipedia isn't built, and scripts can't be hand-edited as a whole after generation (scenes
  can). AI-generated B-roll is Phase 3.
- **Editor:** trims use buttons rather than drag handles. No sound effects, motion graphics or
  intro/outro templates. `text` overlays only come from the hook. B-roll search is on the video page
  (edit a scene's search words), not inside the editor.
- **Consistency risk:** Signal, Documentary and Bold use whatever font the worker machine has for
  `Inter, Helvetica, Arial`, so preview and export can differ slightly. Podcast and Split Runner
  load their fonts explicitly.
- **Podcast:** host voices are assigned automatically, with no per-host picker. No background music
  or sound effects unless a track is uploaded. The hosts are AI voices and must stay labelled.
- **Discovery:** channel monitoring and schedules aren't built. `discovery_sources` is unused,
  though `startDiscovery` accepts a `channelId`. Topic clustering isn't built.
- **Workspaces:** one workspace per user in practice. `requireContext` picks the oldest membership.
  There's no invite flow or switcher, though roles are fully enforced by RLS.
- **Cleanup:** replaced narration and footage stay in storage, and abandoned `pending_upload` rows
  aren't removed. Storage usage counts them.
- **Web host needs ffprobe:** upload validation runs in the web process and resolves `ffprobe-static`
  at runtime, so Next's tracing won't bundle it. On a serverless host, set `FFPROBE_PATH` or include
  the binary. Not tested on any host yet.
- **Operations:** logs go to the console and `/api/health` reports status. No error-reporting
  service, and no request rate limiting beyond Supabase's auth limits. `Dockerfile` not written.
- **Budget timing:** the AI budget is checked when work starts, so a running pipeline can overshoot
  slightly. Cost figures are estimates from configured list prices.
